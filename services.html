Services

Three focused services, not a menu of everything.

Each project is scoped individually — there's no fixed package, because a five-page site and a booking bot don't cost or take the same effort. What follows is what I actually build today, plus what's realistic to add as things grow.

Websites

Custom multi-page websites built in plain HTML, CSS and JavaScript — no page-builder bloat, no unnecessary dependencies. Good for local businesses that need something more credible than a social-media page.

  • Multi-page structure (Home, About, Services, Gallery, Contact — not a single long scroll)
  • Mobile-first, fast-loading, no framework overhead unless the project genuinely needs one
  • Photo galleries, lightboxes, contact forms, custom favicons — the small details that make a site feel finished
  • Basic on-page SEO so the site is actually findable

Bots

Telegram and chat bots that handle a specific, well-defined job — booking a slot, answering FAQs, sending notifications, or collecting leads — rather than trying to be a general-purpose assistant.

  • Built on the Telegram Bot API, with real API integrations (calendars, sheets, external services)
  • Tested against real conversation flows, not just the happy path
  • Clear scope up front — a bot is only useful if it's reliable for the one thing it's meant to do

Workflow automation

Using n8n to connect the tools you already use — forms, spreadsheets, email, Telegram, CRMs — so information moves between them without anyone copy-pasting it by hand.

  • Typical example: a form submission automatically lands in a spreadsheet and triggers a Telegram or email notification
  • Built to be transparent and editable — you're not locked into a black box you can't touch
  • Good fit for repetitive manual tasks that currently eat up real hours every week
On request

Larger custom systems

Bigger internal tools or more complex software are evaluated case by case rather than sold off a shelf — Northloop takes on that kind of work as the team grows, not before it can deliver it properly. If that's what you need, get in touch and I'll tell you honestly whether it's a fit right now.
